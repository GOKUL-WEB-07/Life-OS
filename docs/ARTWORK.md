# Life OS feature artwork

Generated with the built-in imagegen tool. Only feature-specific illustrations are used in the app; the preliminary landscape direction was discarded after the user's clarification.

- public/art/projects-feature.png: cinematic project planning studio with task cards, modular models, planning sheets and a blue milestone timeline, on a pure-black backdrop with open space for a headline.
- public/art/documents-feature.png: organized document folder containing papers, a generic passport, an ID and receipts beneath a glass protective arch; black backdrop, blue/lavender light.
- public/art/ideas-feature.png: warm glowing light bulb above an open sketchbook, sticky notes and connected idea cards; black backdrop and tactile paper.

These prompts deliberately exclude words, logos and readable identifiers. The projects illustration is used for the dashboard hero and Work card, the document illustration for the wallet and bill area, and the idea illustration for brainstorming. They also provide selectable profile cover styles.
